# ☕ Coffee Orders Analysis Project

This folder contains a comprehensive Excel analysis of coffee orders data with interactive dashboards and visual insights.

## Project Overview

A detailed analysis of coffee orders using advanced Excel features including data visualization, pivot tables, and interactive dashboards to understand ordering patterns and business metrics.

## Files

### Data
- `data/coffeeOrdersData.xlsx` — Raw coffee orders dataset with transaction details

### Analysis & Visualization
- `dashboard/coffeeOrdersProject.xlsx` — Complete Excel workbook with analysis, calculations, and interactive dashboard

## How to Use

1. Open `dashboard/coffeeOrdersProject.xlsx` in Microsoft Excel
2. Review the analysis sheets and interactive dashboards
3. Explore the data in `data/coffeeOrdersData.xlsx` to understand the source data

## Technical Implementation

- **Excel Features:** Advanced formulas, pivot tables, data visualization
- **Dashboard Design:** Professional layout with KPI presentations and charts
- **Data Analysis:** Comprehensive order metrics and business insights
